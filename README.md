# AWS Cloud Infrastructure & Web Application Deployment

## 📌 Project Overview

This project demonstrates the design and deployment of basic cloud infrastructure using Amazon Web Services (AWS).

The project includes creating a custom VPC, configuring public and private subnets, setting up internet connectivity, deploying an Ubuntu EC2 instance, and hosting a web application.

## 🏗️ Architecture

The infrastructure consists of:

- Amazon VPC
- Public Subnet
- Private Subnet
- Internet Gateway
- Route Tables
- Security Groups
- Amazon EC2
- Ubuntu Linux
- Node.js
- PM2

## 🎯 Project Objectives

- Create a custom AWS VPC
- Configure public and private subnets
- Configure route tables
- Configure an Internet Gateway
- Deploy an Ubuntu EC2 instance
- Connect to the Linux server
- Install and configure application software
- Deploy a Node.js application
- Manage the application using PM2
- Troubleshoot Linux and application connectivity issues

## 🛠️ Technologies Used

| Technology | Purpose |
